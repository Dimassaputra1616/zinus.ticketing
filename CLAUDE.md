# Zinus Ticketing - AI Context & Rules

## Project Overview
IT Support Center Ticketing system for Zinus Dream Indonesia.

## Tech Stack
- **Framework:** Laravel 11.x (PHP 8.2+)
- **Frontend:** Livewire 3.x, Alpine.js
- **Styling:** Tailwind CSS 3.x/4.x (Vite)
- **Features:** PWA Support, IT Admin & User roles.

## Directory Map
- **Views:** `resources/views/`
- **Livewire Components:** `app/Livewire/`
- **Routes:** `routes/web.php`
- **Assets:** `resources/css/app.css`, `resources/js/app.js`
- **Settings:** `app/Models/Setting.php` (Custom settings system via `setting()` helper)

## Core Rules (Saves Tokens)
1. **Language:** Selalu gunakan Bahasa Indonesia untuk komunikasi dan komentar kode.
2. **UI Style:** Ikuti tema warna Zinus (Zinus Green/Mint).
3. **No Unasked Changes:** JANGAN mengubah kode atau CSS tanpa instruksi spesifik "ratain" (alignment), perbaikan bug, atau penambahan fitur baru.
4. **Auth Compliance:** Selalu pastikan pengecekan user menggunakan `Auth::user()`.
5. **Context First:** Sebelum melakukan riset mendalam, cek file `CHANGELOG.md` atau `README.md` untuk gambaran besar.
